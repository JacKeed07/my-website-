About Me

I'm Zefeng Wang, a student at the University of Texas at Austin currently enrolled in Web Dev for Everyone | Part 1 through the Global Career Accelerator (Fall 2026). Before this course, I was curious about how websites work but had limited experience building complete pages from scratch.

In this program I'm building a foundation in front-end development — semantic HTML, modern CSS layout with Flexbox and Grid, responsive design, and accessibility best practices. I also work extensively with AI tools like GitHub Copilot and ChatGPT to brainstorm designs, generate starter code, and debug faster while I learn to read and edit code myself.

My goal is to keep growing this portfolio with every project I build in this course and beyond, and eventually pursue opportunities where I can combine clean design, accessible code, and real-world problem solving.
